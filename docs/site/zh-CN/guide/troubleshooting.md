# 故障排查与帮助

[文档首页](../index.md) · [账号](accounts.md) · [运维](operations.md)

使用界面安全错误码与请求 ID 关联故障。提供候选/源码版本、配置、时间及其时区、最小复现。不得发送 bearer/会话令牌、Cookie、密码、密钥文件、机密设置、私有内容或签名上传/下载 URL。

## 登录与权限失败

| 现象 | 操作 |
| --- | --- |
| 刷新后失去应用访问 | 用 Account → Sign in 重新顶层授权；应用令牌仅保存在内存 |
| 回调过期或 state 不匹配 | 开始新流程，不复用 code/verifier，也不修改回调参数 |
| 敏感操作要求最近认证 | 重新验证通行密钥；仅密码登录不满足 assurance2 |
| 以前可用的项目/操作被拒绝 | 请授权管理员检查当前成员/账号状态；旧凭据不会冻结权限 |
| 没有恢复邮件或 SSO | 检查实例能力；具体提供方集成尚延后。使用已注册通行密钥、恢复码或实际可用的运营恢复路径 |
| 最后管理员全部方法丢失 | 停止并使用认证运营通道；没有公开绕过或强制密码设置器，重新初始化须满足当前存储前提 |

不要反复提交被拒绝的敏感操作，也不要向声称可以修复会话的人发送凭据。

## 提交、内容与上传失败

冲突时载入当前修订并审阅编辑。表单变更时重新载入定义并检查答案。不确定的提交应原样重试，让回执协调；内容改变属于新提交。导航、刷新、过期、退出或失去访问后草稿可能清空。

语法/复杂度错误需要更小的文档支持查询。`SEARCH_INDEX_INCOMPLETE` 表示授权运营者须完成有界协调；刷新不会触发回退扫描。Minimum 仅搜索标题，搜索模式切换后旧游标失效。

缺少上传配置、空/不允许文件、配额耗尽或预约过期均有解释状态。过期预约需重新上传，不要编辑签名 URL/头。处理、扫描失败或隔离须在放行前解决。隔离下载/预览失败不能作为绕过媒体授权或将未扫描对象视为安全的理由。

## 安装与后台故障

无效配置阻止启动；检查精确公开策略及完整绑定/机密对。就绪503表示主库、密钥、计数器、会话或配置激活前提缺失/不可用。存活探针健康不代表账号/写入就绪。

迁移失败即停止，检查已提交历史/数据，用记录的修复、前向修复或协调恢复。不得改已应用迁移、删除历史或禁用约束。后台延迟时检查主库最老年龄/失败状态、安全异步摘要、租约及提供方就绪，只使用授权重放。Minimum 每个相应阶段间隔25分钟，五分钟无活动可能正常。原生 CPU 归因缺失/不明确或演练调用超过10ms时，停止托管证据采集。

尚未解释的托管实例403仍是后端验收的发布阻塞项。尚未归因其产生方，不能推断应用原因、CPU 成功或权限绕过方案。本发布准备不重启该试验。

## 公开帮助与私密安全报告

普通、非敏感错误可通过 [GitHub Issues](https://github.com/EIHRTeam/HyperBug/issues)报告，包含脱敏复现及版本/配置，先检查已有报告。没有支持响应时间或可用性承诺。

疑似漏洞请使用 [GitHub 私密漏洞报告](https://github.com/EIHRTeam/HyperBug/security/advisories/new)。2026-10-19 的只读仓库 API 检查返回 `enabled: true`，未提交报告。私下提供影响、受影响修订/配置及最小安全复现。不得在公开 Issue 中包含利用细节或凭据。若私密入口不可用，不要公开敏感报告，等待维护者批准的私密通道。不编造邮箱或披露期限。

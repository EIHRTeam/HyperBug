# Troubleshoot and get help

[Documentation home](../index.md)

> Status: Outline only. Product steps and examples are pending implementation and verification.

**For:** Users, project staff, and operators.  
**Goal:** Find the appropriate recovery path and gather useful diagnostics.

## Cannot sign in or access a project

To write: Reserve symptom/cause/recovery entries for expired sessions, revoked permissions, invisible projects and recovery failures; link account guidance.

## Cannot submit or upload

To write: Cover form errors, stale edits, network failures, limits and uncertain completion, using actual user-visible messages once available.

## Installation or background work fails

To write: Reserve operator decision paths for configuration errors, unhealthy dependencies, migration failures, delayed jobs and storage failures.

## Ask for help

To write: Reserve a verified support destination; request version, profile, safe reproduction steps, timestamp and redacted diagnostics. Never request tokens, cookies, secret settings or signed URLs.

## Report a security issue

To write: Reserve a maintainer-approved private reporting channel and disclosure policy. Do not publish vulnerabilities, credentials or sensitive reproductions in public issue discussions. No private contact or response-time commitment is established by this outline.

## Completion requirements

Verify diagnostic paths and support/security destinations with maintainers before publication; use observed failure cases.

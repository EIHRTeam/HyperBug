## Corrections discovered by verification

- The D1 reaction insert built `ON CONFLICT ((columns))` — double parentheses match no constraint; fixed before commit (the reaction uniques existed in migration 0003 all along; a speculative duplicate-index migration was generated and reverted).
- The merged-timeline UNION aligned `revision` with `moderation` by column position in both dialects; both event arms were reordered to identical column sequences.
- The PostgreSQL timeline cursor bound one unreferenced parameter; rewritten to bind each value once.
- A discriminated-union timeline response schema failed Elysia response validation on both profiles; the timeline item schema is flattened with optional per-kind fields.
- V1 verification exposed over-restrictive timeline bodies: non-moderator reads returned comment items without bodies even on public projects, diverging from the comments list. Both adapters now carry bodies for the visible non-deleted rows every audience already sees; hidden/deleted rows keep bodies moderator-only (metadata without bodies), matching the API-CONVENTIONS clarification.
- V3 verification exposed a D1 error-mapping gap: a conditional mutation whose pre-read passed but whose batch lost a race rethrew a raw failure (503) instead of the stable conflict. The D1 mutate catch now classifies lost races by the row's existence — `REVISION_CONFLICT` for a live row, `NOT_FOUND` otherwise — matching the PostgreSQL path.
- V2 verification exposed a moderation leak: the timeline, comment list and reaction surfaces of a hidden issue served every audience that could read the project, because the handlers checked only `issue:read` while the adapters query by `(project_id, issue_id)` without the issue's moderation. Every discussion sub-resource now inherits the issue's own visibility through a shared `requireVisibleIssue` gate — a hidden issue answers 404 to every audience that cannot see the issue itself, and a deleted issue answers 404 to everyone; moderators reach hidden issues' sub-resources exactly like the detail.

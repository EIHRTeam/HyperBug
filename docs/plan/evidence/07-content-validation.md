Raw measurements are linked above. Regression ceilings: mean 1,000 ms per body and 8,000 ms per 100-body page, below the existing 10-second cooperative endpoint deadline. This finite fixture is not a formal worst-case proof of every accepted input, and workerd's local clock is wall time rather than billable CPU.

## Focused implementation review

The policy expands raw HTML before sanitizing, never spreads a provider default allowlist, removes ID/name/event/style/namespace attributes, constrains checkboxes, checks decoded URL schemes plus controls/backslashes/credentials, and converts images into inert references. Source bounds run before recursive parsing; AST bounds run before transform, after raw expansion and after sanitization. Authorization/moderation precede derivation; hidden content is not rendered. Persisted derivatives are limited to versioned plain text. No rendering enters event/receipt/log payloads by default. Backfill compare-and-set protects newer writes and reports rejected IDs without bodies. This is ordinary implementation security verification, not a resumption of suspended audit work.

The Markdown export is a dedicated `@hyperbug/security/markdown` subpath so auth/ingress imports avoid parser initialization. The current minified ingress artifact is 6,893 bytes (an initial eager root export produced approximately 356 KB). API bundles necessarily include the parser; no unrelated dependency/framework upgrade was included.

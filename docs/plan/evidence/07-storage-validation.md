# Module 07 storage validation

Date: 2026-10-03. Scope: 07.3a/07.3i/V3 implemented and verified at the storage layer; immutable promotion groundwork verified. No upload intent, attachment route, quota, release/scan, media delivery or cleanup scheduling acceptance. Audit remains suspended, SPA and Module 09 expansion held.

## Implemented artifacts and review

- Application-owned BlobStore/BlobAuthorization ports, validated opaque staging/final key namespaces, known-length bounded streams, cancellation, range metadata, short-lived signing, bounded metadata/part catalogs and adapter configuration.
- R2 binding adapter plus aws4fetch signer; separate Node AWS SDK v3 adapter/signing. SDK/platform types remain in adapters. See [port specification](../../BLOB-STORAGE.md).
- The final chunk waits for EOF, avoiding a Content-Length receiver committing before a surplus chunk is detected. Node source errors abort HTTP instead of leaving a short request open or raising unhandled stream errors. SHA-256 is incremental in Node and native in R2. Final keys require create-only writes; direct uploads and multipart only accept staging keys. No signed URL is considered single-use, and no HEAD/ETag alone establishes immutable finalization.
- GET snapshots carry total object size and actual delivered size separately. Complete-multipart metadata hydration is staging-only; both adapters compare the completion ETag to the head. Actual R2 completion omitted metadata that its emulator returned; the revised adapter passed the real-service replay.
- Backend signers enforce a maximum 300-second TTL, signed Content-Type, final-only attachment downloads, HTTPS endpoints and no credentials in endpoint URLs. Unit checks reject final-key uploads, malformed keys/metadata, bad multipart catalogs, long expiry, inline dispositions and non-loopback HTTP. SDK errors are mapped without raw provider messages/credentials/URLs. No public route or log-response V5 acceptance is claimed yet.

Focused correctness/security/performance review covered SDK boundary isolation, bounded work and backpressure, source cancellation, error redaction, metadata limits, conditional races, multipart retry ownership, capability namespace/TTL and snapshot/ETag limits. No suspended audit behavior added.
